# A&D — Luxury Streetwear E-Commerce

**Slogan:** *WEAR YOUR IDENTITY.*

A complete, production-ready Vite + React + TypeScript + Tailwind CSS e-commerce web application built for **A&D**.

## Quick Start (Run Locally)

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```
